# GrãoNobre

Landing page do clube fictício de assinatura de cafés especiais GrãoNobre.

## Desenvolvimento

```bash
npm install
npm run dev
```

Para validar o build de produção:

```bash
npm run build
```

## Publicação

Cada push para `main` publica o site no [GitHub Pages](https://marcoaoliveira45-cloud.github.io/land1/).
